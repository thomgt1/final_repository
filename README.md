# Emotion Detector

## Final Project - Emotion Detection Application

This project is an AI-based web application that detects emotions in text using the Watson NLP library.

### Project Description

The Emotion Detector analyzes text and identifies emotions such as:

* Anger
* Disgust
* Fear
* Joy
* Sadness

### Technologies Used

* Python
* Flask
* Watson NLP
* HTML
* CSS
* JavaScript

### Project Objective

To develop a web application that detects emotions from user-provided text and displays the results in a clear and understandable format.
