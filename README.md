# Emotion Detection Web Application

This project is an AI-based web application that detects emotions from customer feedback text.

It uses the Watson NLP Emotion Prediction API to analyze a given sentence and return scores for five emotions:

- anger
- disgust
- fear
- joy
- sadness

The application also identifies the dominant emotion.
